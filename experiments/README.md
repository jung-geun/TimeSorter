## 4B vs 9B 비교

![4B vs 9B](../assets/chart_4b_vs_9b.png)

| 시나리오 | Qwen3.5-4B (n=30) | Qwen3.5-9B (n=150) |
|----------|------------------|--------------------|
| 전체 | **90.0%** | **88.7%** |
| 날짜 혼재 | 100% | 98% |
| 당일 시각 | 100% | 97% |
| 리스크 | 80% | 95% |
| 상대 날짜 | 100% | 93% |
| 의존성 체인 | 67% | **57%** |

> 표본 크기 주의: 4B는 n=30(빠른 평가), 9B는 n=150(전체 held-out). 9B는 비-체인 시나리오에서 93~98%로 매우 안정적이나 **체인은 57%로 여전히 최대 약점** — 모델을 2.3× 키워도 체인은 해결되지 않음.

## 핵심 결론

1. **성능 점프는 데이터 품질과 loss 마스킹에서** — DPO/GRPO 선호 학습 단독으로는 chain 약점 해결 불가
2. **chain 약점은 SFT 데이터 보강이 선행** — dependency_chain은 4B 67%·9B 57%로 모델 크기로도 안 풀림. chain 특화 데이터 증량 필요
3. **Qwen3.5 upgrade 효과** — 동일 데이터셋에서 4B Instruct 77.3% → Qwen3.5-4B 90.0% (+12.7%p)
4. **모델 크기(9B)의 효과는 비-체인 안정화** — 리스크 80→95% 등 약점 시나리오를 평준화하나, 추론 깊이가 필요한 체인은 데이터 문제로 남음
