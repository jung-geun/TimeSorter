# 개선 계획 & 남은 한계

## 남은 한계 (실측)

- **의존성 체인 47~57%** — 4B·9B 모두 미해결. 모델 크기가 아닌 **체인 SFT 데이터 보강**(비중 확대 + 4-5단계 긴 체인)이 필요.
- "오전 마감 + 에스컬레이션" urgency를 4로 과소평가 (가이드는 5).
- 스키마에 구조화된 deadline 필드 부재 — D-day 산술이 텍스트 추론에만 의존.
- 지난 일정 reason 표현 어색 ("오늘 마감이지만 이미 지난" → "어제"로).

## 단기 (데이터)

- **체인 특화 SFT 데이터 3× 증량** (v6 이후 최우선)
- 시간 내 순서(오전<오후) 채점 케이스 강화
- 리스크 키워드(에스컬레이션·위약금·클레임) → importance 상향 케이스 보강
