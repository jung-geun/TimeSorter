## 1. DPO — 발견된 설계 문제 2건

### ⚠️ 문제 1: v2 쉬운 negative가 73%를 차지하고, 그중 절반은 길이 편향 벡터

| 카테고리 | 쌍 수 | rejected/chosen 길이비 | 문제 |
|----------|------|----------------------|------|
| urgency_only (v2) | 3,669 | **0.19** | rejected가 chosen의 1/5 길이 — "짧으면 나쁨"만 배워도 만점 |
| invalid_json (v2) | 3,579 | **0.36** | 형식 위반 — "JSON이면 좋음"만 배워도 구분 가능 |
| bad_scores/shallow_reason (v2) | 7,353 | ~0.9 | 내용 신호는 있으나 패턴이 단순(전부 3점/빈약 사유) |
| v3/v4 hard negatives | 4,200 | **0.96-0.99** | 길이·형식 동일, 내용(날짜/순서/체인)만 오류 — 의도된 설계 |

DPO v2가 rewards/accuracies 1.0으로 수렴하고도 검증에 실패한 원인이 데이터에서 재확인됨.
**전체 통합본을 그대로 학습하면 쉬운 신호가 hard negative를 희석한다.**

### ⚠️ 문제 2: v1 쌍 1,468개는 chosen이 자유 텍스트 (JSON 0%)

v3 시스템 프롬프트("JSON으로만 응답")와 모순되는 chosen을 선호하도록 가르치게 됨.
v1 어댑터 재현 외에는 학습에 사용하면 안 된다.

### ✅ 정상 확인 항목

- eval(held-out) 프롬프트 누수 0건, chosen==rejected 0건
- 프롬프트당 쌍 수 최대 7 (동일 입력에 다른 negative — DPO에서 정상)
- v3/v4 쌍의 18%는 점수 동일·순서만 다름 (순서-점수 일관성 직접 벌점)

### 조치 (적용 완료)

`dpo_train.parquet`에 `tier` 컬럼 추가:
- `hard` — v3/v4 내용 오류 negative (4,200쌍): **DPO 본 학습 권장**
- `easy_format` — v2 형식·단순 negative (14,601쌍): 초기 형식 안정화 또는 소량 혼합용
- `refusal` — 거부 쌍 (720쌍): 거부 능력 유지용으로 항상 혼합 권장
- `legacy_text` — v1 자유 텍스트 (1,468쌍): v3+ 학습에 사용 금지
